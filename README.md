# La Jhinga | Seafood | Cafe — Palolem Beach, Goa

A luxury, coastal React SPA for **La Jhinga | Seafood | Cafe** located near Palolem Beach (Beach Road / T-Junction), Canacona, South Goa.

## 🌟 Key Features
- **Light & Warm Coastal Theme**: Warm Sand `#FFF8F5`, Deep Teal `#014E68`, Coral `#FF8F72`, Light Teal `#5BC5D2`, and natural open-air card styling.
- **Conversion-Optimized**: Direct Call actions (`tel:8287696969`) and instant Table & Dining Reservation modal with WhatsApp pre-filled messaging.
- **Social Proof**: Google Rating 4.7 ★ with 408 Reviews and theme filter pills.
- **Visuals**: Full interactive masonry gallery with category filters and lightbox modal.
- **Decoupled Local Data**: All content, seafood catch specials, multi-cuisine offerings, and reviews are managed in `src/data/laJhinga.js`.

## 🚀 Running the Project
```bash
npm install
npm start
```
Runs at `http://localhost:3000`.

## 📦 Building for Production
```bash
npm run build
```
Generates an optimized static production bundle in `build/`.
