# Asset Storage Guidelines

This directory is prepared for placing custom client photography and video media.

## Directory Structure:
- `src/assets/ninepm/` : Nightlife, DJs, cocktails, sushi/kebabs, crowd, and lounge photos.
  - `hero.jpg`
  - `dj-night.jpg`
  - `cocktails.jpg`
  - `food-sushi.jpg`
  - `food-kebabs.jpg`
  - `lounge.jpg`
  - `gallery-01.jpg` ... `gallery-06.jpg`

- `src/assets/lajhinga/` : Coastal seafood, open-air cafe, live acoustic sessions, and Palolem beach atmosphere.
  - `hero.jpg`
  - `seafood-pomfret.jpg`
  - `seafood-prawns.jpg`
  - `multi-cuisine-goan.jpg`
  - `multi-cuisine-indian.jpg`
  - `open-air-dining.jpg`
  - `live-music.jpg`
  - `gallery-01.jpg` ... `gallery-06.jpg`

To update images, simply drop the image files here and import or update the image path references in `src/data/ninePM.js` and `src/data/laJhinga.js`.
